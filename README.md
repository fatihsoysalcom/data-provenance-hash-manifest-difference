# Data Provenance Hash Manifest Difference

This example demonstrates how a dataset's digital fingerprint (hash) is influenced by both its content and its associated provenance manifest. It shows how changes in either the data or the manifest lead to a different hash. Critically, it illustrates how comparing the manifests can explain the reason behind a hash change, showcasing the concept of 'manifest difference' for data provenance.

## Language

`python`

## How to Run

Save the code as `main.py`.
Run from your terminal: `python main.py`.
